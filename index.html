How it works

No server, no agent, no tenant access needed to get the report.

Export from IdentityIQ

Use the IIQ console to export applications, rules and the identity config.

export -clean apps.xml Application
export -clean rules.xml Rule

Run one command

Python 3.10 or newer. Nothing to install. Takes seconds.

python3 -m iiq2isc exports -o output

Review, then push

Open the gap report, then import the JSON your usual way or push to a sandbox tenant with a dry run first (beta).

open output/gap-report.html

Questions

Does it need access to my IdentityIQ server or ISC tenant?

No. You export XML from IdentityIQ yourself and run the toolkit on your laptop. Tenant access is only needed if you choose to use the push command.

Will it migrate everything automatically?

No tool can do that honestly, because many IdentityIQ customizations have no direct ISC equivalent. IdentityLift converts what it safely can and lists everything else with the recommended ISC approach and an effort estimate.

Is the push command production ready?

Push is in beta. Always run the dry run first and use a sandbox tenant. It never overwrites objects that already exist.

What do I need to run it?

Python 3.10 or newer on macOS, Windows or Linux. There's nothing else to install.

Is IdentityLift part of SailPoint?

No. IdentityLift is an independent tool built by SailPoint engineers. It is not affiliated with or endorsed by SailPoint Technologies.
